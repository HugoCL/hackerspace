# Stack

Flexbox con espaciado de la escala: columna por defecto, `direction="row"` para filas.

- `gap` acepta pasos de la escala: `1` (4px), `2` (8px), `4` (16px, por defecto), `6` (24px), `12` (48px). Cualquier otro valor CSS se pasa tal cual, pero prefiere la escala.
- `align`, `justify` y `wrap` mapean a flexbox. `as` cambia la etiqueta (p. ej. `ul`).
- Para colecciones de tarjetas usa `Grid`, no Stack con wrap.
