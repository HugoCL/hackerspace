# Separator

Una línea `ui-border` que separa grupos dentro de una tarjeta, un menú o un formulario. Con `label` lleva un texto centrado ("o").

- Antes de separar, prueba con espacio: `space-6` suele bastar. La línea es para grupos de distinta naturaleza.
- No la uses entre Sections de una página (ya las separa `space-12`).
- En la app: `@ui-sdk/react/separator`.
