# Grid

Grilla responsiva de tarjetas: columnas automáticas de al menos `min` px (280 por defecto) con `gap` 24px.

- Hackathones y equipos: `min={280}`. Proyectos (con imagen): `min={260}`. Estadísticas o chips: `min={160}`.
- No fijes número de columnas: la grilla se adapta del móvil (1 columna) al escritorio.
- Todas las tarjetas de una grilla son del mismo tipo y se estiran a la misma altura.
