# AvatarStack

Varias personas superpuestas, hasta `max` (5), con "+N" para el resto.

- Pasa `total` cuando conoces el total real pero solo tienes algunas caras (p. ej. "148 viendo", 5 avatares).
- Ordena primero a quienes el usuario conoce (amigos, compañeros de equipo).
- Tamaño `xs` dentro de PresencePill y tarjetas, `sm` en encabezados.
