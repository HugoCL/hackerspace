# Badge

Etiquetas cortas. Tonos: `neutral` (temas, tecnologías), `presencial` (contorno de tinta, ícono pin), `virtual` (azul, ícono globe), `signal` (lima: roles buscados, premios), `live` (algo pasando ahora) y `danger`.

- Una a tres palabras, sin punto final.
- Modalidad siempre como Badge, primero en la tarjeta.
- `live` solo para estados de tiempo real ("Activo ahora", "En curso"). Para contar gente viendo usa PresencePill.
- `signal` con moderación: si todo es lima, nada destaca.
