# ProjectCard

Un proyecto en la galería: imagen 16:9 (o un marcador con `code`), premio opcional, título, descripción, tecnologías, equipo, hackathon y "me gusta".

- `image`: captura o portada del proyecto. Sin imagen, el marcador gris es correcto; no inventes ilustraciones.
- `award`: solo premios reales de la hackathon ("1er lugar", "Mejor uso de IA"), en Badge lima con trofeo.
- `likes` con números tabulares; no muestres 0.
- En Grid con `min={260}`.
