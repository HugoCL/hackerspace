# TeamCard

Un equipo que se está armando: nombre, hackathon, el pitch en una línea, qué roles buscan (Badges lima), sus cupos y la acción.

- `lookingFor`: roles concretos, máximo 3 ("Frontend", "Diseño", "Hardware").
- `activeNow` cuando algún integrante está conectado: muestra "Activo ahora".
- `action`: normalmente `Button variant="signal" size="sm"` "Postular". Si el usuario ya está en el equipo, cámbialo por "Ver equipo" `secondary`.
