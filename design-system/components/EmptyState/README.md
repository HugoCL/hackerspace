# EmptyState

Cuando una lista está vacía: tres asientos punteados, un título que invita y una acción.

- El título dice qué falta y por qué importa: "Nadie está buscando equipo aún".
- La descripción invita a ser el primero; la acción hace eso posible ("Publicar que busco equipo").
- Nunca un error disfrazado: si falló la carga, dilo.
