# Pagination

Navegación entre páginas de una lista larga: Anterior, números con saltos y Siguiente.

- Para tablas y listados con orden estable (resultados, participantes). En catálogos que se exploran (hackathones, proyectos) prefiere un botón "Ver más".
- Controlado (`page` + `onChange`) o no controlado (`defaultPage`); `pageCount` es el total.
- Con una sola página, no lo muestres.
- En la app: `@ui-sdk/react/pagination`.
