# Tooltip

Una etiqueta corta que aparece al pasar el cursor o enfocar un control, sobre todo los botones de solo ícono.

- Una a cuatro palabras, sin punto. Nombra el control; no expliques cómo se usa.
- Nunca pongas ahí información necesaria: en pantallas táctiles no se ve.
- Envuelve un solo elemento enfocable. `side="bottom"` cuando arriba no hay espacio.
- En la app: `@ui-sdk/react/tooltip`.
