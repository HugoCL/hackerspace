# Avatar

Una persona: foto o iniciales en un círculo (`radius-full`). Tamaños `xs` 20, `sm` 28, `md` 36, `lg` 56.

- Sin foto, el fondo sale de cuatro tonos del sistema elegidos por el nombre: la misma persona siempre tiene el mismo color.
- `online` agrega el punto `hs-live`: la persona está en Hackerspace ahora. No lo uses para "disponible para equipo" (eso es un Badge `signal`).
- Siempre pasa `name`: es la etiqueta accesible.
- Los agentes **no** tienen Avatar: se muestran con AgentTag.
