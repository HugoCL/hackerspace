# Alert

Un mensaje dentro de la página que no desaparece solo: un aviso, algo que pasa ahora, una confirmación o un error.

- Tonos: `info` (neutro), `live` (naranja: está pasando ahora), `success` (lima: se logró algo importante) y `danger` (error o riesgo).
- Título de una frase que dice qué pasó; descripción que dice qué hacer. Los errores no piden perdón ni son vagos.
- `action`: un Button `sm` como máximo.
- Para algo breve que sí puede desaparecer (se guardó, alguien se unió), usa Toast.
- `success` con moderación: la lima es el color de marca.
