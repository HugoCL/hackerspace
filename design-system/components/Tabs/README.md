# Tabs

Pestañas para cambiar de subvista dentro de una página: Resumen · Bases · Equipos · Proyectos en el perfil de una hackathon, o Presenciales · Virtuales en Explorar.

- 2 a 6 pestañas, sustantivos de una o dos palabras. `count` para totales.
- Controlado (`value` + `onChange`) o no controlado (`defaultValue`).
- Debajo de PageHeader y antes del contenido; no las anides.
- Para filtros combinables usa `Select` o chips, no Tabs.
