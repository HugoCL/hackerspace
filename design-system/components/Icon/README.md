# Icon

Íconos lineales de 1.5px en `currentColor`: search, pin, calendar, users, heart, plus, bell, bot, trophy, globe, arrow, menu, code, check, x, chevron, info, alert, more.

- 16px en controles y texto, 14px en metadatos de tarjeta, 20–28px en estados vacíos.
- Decorativos por defecto (`aria-hidden`). Pasa `label` si el ícono es la única información.
- `bot` está reservado para lo que hace un agente (lo usa AgentTag). `pin` = presencial, `globe` = virtual.
- Set provisional; para más íconos usa Lucide con el mismo trazo de 1.5px.
