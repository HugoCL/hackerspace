# Breadcrumb

La ruta hasta la página actual, para volver un nivel: Explorar / Santiago Hacks 2027 / Equipos.

- Va en el eyebrow del PageHeader. El último elemento es la página actual y no es enlace.
- Solo en páginas con dos o más niveles; en las de primer nivel la navegación del AppShell basta.
- Usa los mismos nombres que la navegación y los títulos.
