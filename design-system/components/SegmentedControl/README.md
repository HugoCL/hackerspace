# SegmentedControl

Dos a cuatro opciones cortas, una activa, que cambian lo que se ve sin salir de la página: Todas / Presenciales / Virtuales, o Lista / Mapa.

- Es el "toggle group" del sistema. Úsalo para filtrar o cambiar de vista; para secciones con contenido distinto usa Tabs.
- Etiquetas de una palabra. `icon` y `count` opcionales por opción.
- `label` nombra el grupo para lectores de pantalla (no se muestra).
- En la app: `@ui-sdk/react/segmented-control`.
