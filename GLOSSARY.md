# Glosario de Hackerspace

Usa inglés en el código, identificadores y nombres de archivos, y español en el texto de la interfaz.

| Término | Código | Significado |
| --- | --- | --- |
| Hackathon | `hackathon` | Evento presencial o virtual en el que las personas construyen proyectos. |
| Perfil de hackathon | `hackathonProfile` | Ficha de un evento que reúne sus detalles, bases y reglas. |
| Bases | `eventGuidelines` | Condiciones oficiales de participación, como requisitos, fechas y entregables. |
| Reglas | `rules` | Normas de participación y evaluación definidas por la organización. |
| Equipo | `team` | Grupo de personas que se reúne para participar en una hackathon. |
| Proyecto | `project` | Trabajo que se construye durante una hackathon y se puede compartir en la galería. |
| Galería de proyectos | `projectGallery` | Espacio para descubrir proyectos compartidos. |
| Presencia | `presence` | Indicación en vivo de quién está viendo un espacio, como el perfil de una hackathon. |
| Scout | `scout` | Agente de Hackerspace que usa Firecrawl para descubrir hackathones y crear perfiles que aún no existen. |
| Agente del usuario | `userAgent` | Agente externo que usa las funciones permitidas de Hackerspace vía MCP o API, sujeto a límites de uso. |
