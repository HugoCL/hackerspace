# TeamSlots

Los cupos de un equipo: integrantes como avatares, lugares libres como círculos punteados con +, y "2 lugares libres".

- `size` es el máximo del equipo según las bases de la hackathon.
- Con lugares libres la etiqueta va en `hs-live-ink` (es una invitación); completo, en gris.
- `online` en cada integrante si está conectado ahora.
