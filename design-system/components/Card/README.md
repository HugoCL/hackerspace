# Card

La superficie base: `hs-surface` con borde `ui-border` y radio `radius-md`. Sin sombra.

- Con `href` es un enlace completo y se marca al hover con el borde `ui-input`. `interactive` da el mismo aspecto sin enlace.
- `padding="none"` para tarjetas con imagen a sangre (ProjectCard).
- Prefiere las tarjetas de dominio (HackathonCard, TeamCard, ProjectCard). Usa Card sola para paneles laterales y contenido propio.
- No anides tarjetas.
