# Drawer

Un panel que entra desde la derecha (desde abajo en móvil) para contenido largo o de consulta sin perder la página: filtros, el detalle de una persona, las bases completas.

- Es el "sheet" del sistema. Mismas props y reglas de título y pie que Dialog.
- Úsalo cuando la persona necesita volver a lo que estaba mirando; para decisiones cortas, Dialog.
- El pie queda abajo: "Aplicar filtros" a la derecha, "Limpiar" a la izquierda.
- En la app: `@ui-sdk/react/drawer`.
