# Accordion

Secciones que se abren y cierran: preguntas frecuentes y las bases y reglas largas de una hackathon.

- Por defecto solo una abierta a la vez; `multiple` deja abrir varias.
- El título es la pregunta o el nombre de la regla, completo. La respuesta, texto corrido de menos de 72 caracteres por línea.
- No escondas aquí lo que casi todos necesitan (fecha, lugar, tamaño de equipo): eso va visible.
- En la app: `@ui-sdk/react/accordion`.
