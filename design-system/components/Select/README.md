# Select

Selección nativa con el mismo aspecto que Input. Para filtros (modalidad, ciudad, fecha) y formularios.

- `options` acepta strings u objetos `{value, label}`.
- Primera opción = el valor por defecto con sentido ("Cualquier fecha"), no "Selecciona…".
- Hasta ~12 opciones; más que eso pide un buscador.
