# Switch

Enciende o apaga algo que se aplica al instante, sin botón Guardar: "Abierto a invitaciones", "Mostrar que estoy viendo".

- La etiqueta nombra lo que queda encendido. No cambies el texto según el estado.
- Si el cambio necesita confirmación o va dentro de un formulario con Guardar, usa Checkbox.
- En la app: `@ui-sdk/react/switch`.
